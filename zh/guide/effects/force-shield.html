类型

类

ForceShield 是包裹球体的六边形力场。三平面六边形网格、菲涅尔边缘、分层流动噪声和逐格闪烁共同构成表面；噪声阈值让外壳可以溶解，从而收放护盾，溶解边缘在移动时会发亮。

hit(point) 从世界空间接触点发射冲击环并消耗生命值，life 下降时表面会逐渐偏向红色。护盾由自身时钟驱动动画，溶解与冲击环都不需要逐帧代码。

<template>
  <tv-scene class="scene" bg-color="rgb(40, 42, 54)" @created="created"></tv-scene>
</template>

<script lang="ts" setup>
import { onBeforeUnmount } from 'vue'
import * as THREE from 'three'
import { ForceShield } from 'three-vue3'

let effect: ForceShield | undefined
let timer: ReturnType<typeof setInterval> | undefined
let removeListener: (() => void) | undefined

const created = (scene, { camera, controls }) => {
  if (!camera || !controls) return

  camera.position.set(0, 0.8, 4.6)
  camera.lookAt(0, 0, 0)

  effect = new ForceShield({ radius: 1.8, hitDamage: 3 })
  scene.add(effect)

  // 点击力场时，在射线命中处产生冲击。
  const raycaster = new THREE.Raycaster()
  const pointer = new THREE.Vector2()

  const handlePointerDown = (event: PointerEvent) => {
    const canvas = controls.domElement
    const rect = canvas.getBoundingClientRect()
    pointer.set(
      ((event.clientX - rect.left) / rect.width) * 2 - 1,
      -((event.clientY - rect.top) / rect.height) * 2 + 1
    )
    raycaster.setFromCamera(pointer, camera)
    effect?.hit(raycaster.intersectObject(effect)[0]?.point)
  }

  controls.domElement.addEventListener('pointerdown', handlePointerDown)
  removeListener = () => {
    controls.domElement.removeEventListener('pointerdown', handlePointerDown)
  }

  // 自动冲击让演示持续运动；生命耗尽后重置护盾。
  timer = window.setInterval(() => {
    if (!effect) return
    effect.hit()
    if (effect.life < 0.6) effect.life = 1
  }, 1400)
}

onBeforeUnmount(() => {
  removeListener?.()
  removeListener = undefined
  if (timer) {
    window.clearInterval(timer)
    timer = undefined
  }
  effect?.dispose()
  effect = undefined
})
</script>

配置项

名称类型默认值描述
radiusnumber1.8可选 球体半径。
activebooleantrue可选 护盾处于展开还是溶解状态。
revealnumber—可选 将溶解冻结在该进度（0 可见，1 完全溶解）。
revealSpeednumber3.5可选 自动溶解动画的速度。
colorColorRepresentation0x26aeff可选 护盾基础颜色。
opacitynumber0.76可选 表面整体不透明度。
hexScalenumber3可选 六边形网格平铺密度。
hexOpacitynumber0.13可选 六边形单元格亮度。
showHexbooleantrue可选 是否绘制六边形网格。
edgeWidthnumber0.06可选 六边形缝隙宽度。
fresnelPowernumber1.8可选 菲涅尔衰减指数。
fresnelStrengthnumber1.75可选 菲涅尔边缘亮度。
fadeStartnumber0可选 低于该 Y 值淡出到地面，-1 关闭。
flashSpeednumber0.6可选 单元格闪烁速度。
flashIntensitynumber0.11可选 单元格闪烁亮度。
noiseScalenumber1.3可选 溶解噪声缩放。
noiseEdgeColorColorRepresentation0x26aeff可选 溶解边缘颜色。
noiseEdgeWidthnumber0.02可选 溶解边缘宽度。
noiseEdgeIntensitynumber10可选 溶解边缘亮度。
noiseEdgeSmoothnessnumber0.5可选 溶解边缘锐利度。
flowScalenumber2.4可选 流动噪声缩放。
flowSpeednumber1.13可选 流动噪声速度。
flowIntensitynumber4可选 流动噪声亮度。
hitRingSpeednumber1.75可选 冲击环扩散速度。
hitRingWidthnumber0.12可选 冲击环粗细。
hitMaxRadiusnumber0.85可选 冲击环最大角半径。
hitDurationnumber1.8可选 冲击可见的持续秒数。
hitIntensitynumber4.1可选 冲击亮度。
hitImpactRadiusnumber0.3可选 接触高亮的角半径。
hitDamagenumber5可选 每次命中扣除的生命值百分比。
lifenumber1可选 初始护盾生命值（1 完好，0 耗尽）。

类用法

import * as THREE from 'three'
import { ForceShield } from 'three-vue3'

const shield = new ForceShield({ radius: 1.8 })
scene.add(shield)

// 溶解与冲击环由护盾自身时钟推进。
// 溶解收起，然后重新展开：
shield.setActive(false)
shield.setActive(true)

// 在世界空间某点触发冲击：
shield.hit(new THREE.Vector3(1, 0.6, 1.2))

// 销毁时：
shield.dispose()
