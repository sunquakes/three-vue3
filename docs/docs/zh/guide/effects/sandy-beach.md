第一人称的黎明海滩漫步。小岛是一个周长 260 米的环形海岸，沙面高度、湿沙带、海浪起伏与脚印共用同一套海岸坐标，因此无论走到哪个角度，水线、行走者与着色器都始终对齐。整片海滩由一次全屏光线步进（ray-march）完成：在同一份 TSL 着色器里求值沙面高度场与水面，最后套用 ACES 色调映射 —— WebGPU 与 WebGL 渲染器编译的是同一份着色器，画面完全一致。场景只为沙与水着色：两者都没命中的光线直接填充 Scene 的背景色，因此画布保持不透明。

拖动可以环顾四周，用 `WASD` 或方向键行走，滚轮向前迈出一步。脚印写入一个很小的环形缓冲，再被潮水慢慢抹去。

## 交互

- **拖动**转动视角。视角拖动只绑定在画布上，因此环顾时页面不会跟着滚动。
- **`W` / `A` / `S` / `D`** 或**方向键**在沙滩上行走。只有指针位于画布上方时键盘输入才会生效。
- **滚轮**以一次短促的推力向前迈步，而不是连续缩放。
- 行走者被限制在沙滩环内，摄像机不会走进海里，也不会爬上内陆的坡地。

## 配置项

| 属性        | 类型                                                       | 默认值    | 描述                                                                    |
| ----------- | ---------------------------------------------------------- | --------- | ----------------------------------------------------------------------- |
| preset      | `'sunrise' \| 'morning' \| 'sunset' \| 'night' \| 'blueHour'` | `'sunrise'` | `optional` 一天中的时段预设。切换时阳光、水面与沙地颜色会交叉淡入。    |
| autoWalk    | `boolean`                                                  | `false`   | `optional` 自动向前行走，适合做背景动画。                                |
| crouching   | `boolean`                                                  | `false`   | `optional` 把摄像机降低到蹲下的视高。                                    |
| interactive | `boolean`                                                  | `true`    | `optional` 为画布绑定拖动视角、`WASD` / 方向键与滚轮迈步。              |

## 预设

| 预设     | 描述                                                          |
| -------- | ------------------------------------------------------------- |
| sunrise  | 温暖的低角度阳光，桃色浅滩与沙面上细长的柔和阴影              |
| morning  | 高角度阳光，明亮的青绿浅滩与浅色干沙                          |
| sunset   | 阳光几乎贴在水面上，橙色波光带与紫调的沙面                    |
| night    | 冷色月光洒在深色水面与暗哑的沙面上                            |
| blueHour | 太阳刚落到地平线下，粉色光线映在幽蓝的水面上                  |

## 说明

- 组件挂载期间接管摄像机。它会保存之前的摄像机姿态、视场角与近远裁剪面，禁用场景的 `OrbitControls`，并在卸载时全部还原。
- 场景由一颗内翻的球体承载一份全屏 TSL 着色器：它对沙面做球体步进、求交动态水面，再着色更近的那个交点，包含深度吸收的浅滩、泡沫、湿沙与脚印。两者都没命中的光线直接填充 Scene 的背景色，使画布保持不透明，并确保两种渲染器的输出一致。
- 所有几何体、材质、纹理与事件监听都会在卸载时释放。
- 修改配置项只会在原地更新正在运行的场景，不会重建海滩。
